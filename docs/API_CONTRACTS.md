# Daktar Khata - API Contracts

The following represents the major API controllers present in the `apps/backend/src/modules/` directory. Each controller typically implements CRUD endpoints for its respective entity. 

_Note: Swagger documentation is auto-generated by the backend and available at `/api-docs` when the server is running. This document serves as a high-level overview._

## 1. Core Platform
- **Auth**: `/auth` - Login, registration, token refresh.
- **User**: `/users` - User profile, management. (Includes broken `users/me` -> `users/profile` and `users/admin/create` endpoints).
- **Permissions**: `/permissions` - Role and permission management.
- **Dashboard**: `/dashboard` - Overview statistics (currently uses mock data).

## 2. Multi-Tenant / Clinic
- **Clinic**: `/clinic` - Clinic information management.
- **Merchant**: `/merchant` - Merchant tenant management.
- **Merchant PG**: `/merchant-pg` - Payment Gateway configuration for merchants.
- **Staff**: `/staff` - Staff management and attendance.
- **Staff Role Template**: `/staff-role-template` - Customizable roles for clinics.

## 3. Clinical Workflow
- **Patient**: `/patient` - Patient registration and demographics.
- **Doctor**: `/doctor` - Doctor profiles and schedules.
- **Appointment**: `/appointment` - Booking and managing appointments.
- **Medical Records**: `/medical-record` - Patient clinical history.

## 4. Billing & Finance
- **Finance**: `/finance` - Financial overview.
- **Income**: `/income` - Income tracking.
- **Expense**: `/expense` - Expense tracking.
- **Payment**: `/payment` - Payment processing.
- **Subscription**: `/subscription` - SaaS subscription plans for merchants.
